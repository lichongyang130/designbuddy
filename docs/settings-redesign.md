# 设置中心统一改版

## 设计与结构

- [x] 统一设置窗口、搜索、分组导航、页头与关闭按钮。
- [x] 暖灰背景、白色卡片、低饱和绿色强调；深色主题使用独立语义配色。
- [x] 统一标题、说明、输入框、下拉框、按钮、开关、成功与失败反馈。
- [x] 桌面最大 1060 × 800；640px 以下切换顶部横向导航，内容独立滚动。
- [x] 键盘焦点边框、Tab 循环、Escape 关闭、主题预览方向键与 Home / End 操作。
- [x] 模型编辑器与父设置窗口区分关闭按钮，嵌套模态框独立处理 Tab。
- [x] 尊重 reduced-motion；紧凑模式调节间距，不缩小关键文字。

## 真实性与边界

- 不新增后台不存在的收费、同步、在线状态、自动学习、安全评分或授权能力。
- 资料、记忆、密码、扩展和应用状态复用已有 API，未修改后端协议。
- 专业角色详情、完整应用授权、扩展安装/卸载和账号数据管理仍通过现有完整管理页进入。
- 数据概览仅统计当前浏览器可读取的本地数据，不代表服务端数据库大小或设备容量。
- 密钥沿用原会话存储，不写入可同步模型偏好。
- 新增文案有简体中文与英文；其他语言沿用现有翻译，新增文案回退英文，并诚实显示翻译不完整提示。没有把英文回退冒充完整翻译。
- 测试会话、数据库、截图及构建输出不上传 Git。
