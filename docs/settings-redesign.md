## 真实性与边界

- 不新增后台不存在的收费、同步、在线状态、自动学习、安全评分或授权能力。
- 资料、记忆、密码、扩展和应用状态复用已有 API，未修改后端协议。
- 保留专业角色详情、连接器目录、扩展市场和账号数据管理页作为补充入口；本轮设置内功能不再仅依赖这些跳转。
- `/api/connectors` 及其授权/断开接口当前返回 503 `NOT_CONFIGURED`。本轮接入其前端合同，不实现或冒充尚未部署的真实 OAuth 服务。账号 Google/GitHub 登录不等于应用连接器授权。
- 本地自定义应用配置不自动建立连接或执行 MCP 调用。授权状态只取自通过结构验证的服务端响应，不信任本地 `connected` 标志或回调查询参数。
- 数据概览仅统计当前浏览器可读取的本地数据，不代表服务端数据库大小或设备容量。
- 密钥沿用原会话存储，不写入可同步模型偏好。
- 本设置设计目录共 160 个键，除中英文外已补齐其余 17 种语言（共 19 种），并检查插值参数。通用操作复用语义一致的已有译文。
- 原有目录中部分非本轮新增的模型编辑器/框架文案仍有英文回退，因此保留既有的翻译不完整提示；没有把本轮目录覆盖冒充全应用翻译完成。角色名称、目录描述、后端诊断等内容数据不在界面翻译范围。
- 测试会话、数据库、截图及构建输出不上传 Git。

## 本轮功能补齐与验证（2026-10-19）

### 实际行为

- 角色配置经清洗后写入已有偏好存储并参与偏好迁移/账号同步；上限 100 个覆盖项，职责 1,200 字、附加规范 400 字。恢复默认需确认，并释放覆盖项。
- 停用会排除自动匹配、手动候选与专家详情页启动；启用不代表后台代理或外部工具获权。
- 自动匹配最多向模型提供 25 个自定义候选；该网络请求上限不影响手动选择更多自定义角色，手动选择也会携带其保存规范。
- 自动匹配同意默认关闭，保存在本机，不由账号同步开启。等待时间为 0.9 / 1.5 / 3 秒；协作开关控制后续执行规范。关闭会取消待发匹配、使在途结果失效。存储失败也会先在当前页面停止草稿分享，但会明确报错，无法保证重载后保留失败的写入。
- 扩展安装、卸载、启停均调用现有 API，并等待成功后回读；卸载的非 2xx 响应不会再误报成功。测试使用明确的 API fixture，不构成真实第三方扩展认证。
- 模型结果只在当前运行内存保留，修改模型/端点/密钥或重载后不能沿用旧的成功结果。15 分钟后失效（每分钟刷新），状态有核验时间；仅检查提供商的模型列表，不代表生成、计费或全部能力已验证。服务端托管模型保持未核验，并提示到模型与用量页检查。
- 应用公开配置可在当前 503 后端环境下独立管理；地址必须为无凭据、查询、片段的公网 HTTPS。只为已有 GitHub/Notion 合同展示授权入口，校验提供商授权域名/路径、处理弹窗阻止、返回后重新读取状态。
