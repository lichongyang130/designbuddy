## 已交付范围，而不是全方案完成

从任务说明预设中分离可执行技能。新增三个固定程序执行器，绑定四个核心专家：

|技能|专家|真实输入/输出|
|---|---|---|
|table.analyze v1|数据分析、信息可视化|CSV/XLSX首表 → 清洗XLSX、字段统计JSON、SVG概览、运行凭据|
|document.format v1|文档整理|TXT/MD/DOCX主文档正文 → 可编辑DOCX、来源段落JSON、运行凭据|
|slides.compose v1|汇报提案|TXT/MD/DOCX → 确定性分页的可编辑PPTX、内容预览HTML、来源段落JSON、运行凭据|

真实代码读取、计算、写文件并回读Office包校验；不依赖AI、不访问外网、不执行上传内容里的代码。不是十二位专家全部实现。其余八位的技能注册为 `unavailable`，不开放执行按钮。

文档不做语义总结；PPT不做论证、配图或PowerPoint渲染。HTML仅是内容预览。没有PDF解析/导出、OCR、外部邮件、图像生成/编辑、隔离全栈环境或浏览器验收。普通聊天仍然只应用专家方法，尚未接入模型自主调用这些技能的闭环。

## 使用入口

- 专家详情 → 已接通技能：选择实际文件、选择去重选项（默认保留）、确认上传到应用后台 → 执行。
- 技能页顶部 → 技能执行与运行记录：查看注册版本、专家绑定、真实输出及限制，运行已接通技能。
- 原技能市场保留个人收藏/自建数据，但明确标为“任务说明预设”；“安装”改为“添加”，删除占位使用量。
- 返回或刷新后，从“我的运行记录”继续查看状态/成果；删除会删除该次上传及成果，不影响历史聊天任务。
- 后台检查失败时显示错误，不用前端常量假装后台可用。用户明确确认后才上传文件；此服务端入口不是首页的仅浏览器本地模式。

## 后台架构

- `shared/skillRuntime.ts`：技能契约、版本、专家绑定、输入输出、边界；运行状态与成果类型。
- `server/skills/executors.ts`：白名单固定执行器，参数/文件校验、真实转换与成果回读。
- `server/skills/worker.ts`：Worker线程入口。V8内存限制、45秒超时，允许取消；不是可运行任意用户代码的安全沙箱。
- `server/skills/service.ts`：单实例队列（并发2、活跃任务最多20）、SQLite持久化、证据、所有者隔离下载/删除。
- `data/skill-runs.sqlite`：独立于原工作区数据库；已被Git忽略。不移动、不清理原有用户数据库。
- 服务重启会把未结束任务标为失败，不擅自重放。成功任务保留。无自动重试或外部副作用。

接口由现有会话鉴权保护，浏览器写请求沿用本地daemon的同源检查：

- `GET /api/skill-runtime`
- `POST /api/skill-runs`（multipart：file、skillId、expertId、consent、deduplicate）
- `GET /api/skill-runs`（当前用户的记录）
- `GET /api/skill-runs/:id`
- `POST /api/skill-runs/:id/cancel`
- `GET /api/skill-runs/:id/artifacts/:artifactId`
- `DELETE /api/skill-runs/:id`

每个运行保存输入SHA-256、技能版本、选项、实际事件、结果摘要；成果保存SHA-256、MIME和大小。下载强制attachment、nosniff、no-store及沙箱CSP。页面HTML预览iframe不授予脚本或同源权限。

## 格式与资源边界

- 上传最多2MB；每用户100次运行、输入+成果100MB，全局输入+成果1GB。无定期自动删除，用户主动管理。
- 单次输出合计最多10MB。文件留存于应用服务器，不称云同步；SQLite逻辑删除不承诺磁盘介质安全擦除。
- CSV仅UTF-8，表头非空且唯一，各行列数一致。最多5000行、50列、100000单元格。多余工作表不处理，报告记录首表名。
- 去重仅删除所有字段完全相同的记录，默认关闭；CSV来源为解析后逻辑记录序号（不等于物理文本行号）。
- XLSX拒绝公式、宏、外链、嵌入对象及复杂单元格，不使用过时公式缓存。
- ZIP中央目录/本地条目/路径/条目数量/压缩比/解压大小预检查；XML拒绝DOCTYPE、ENTITY和外部关系。
- 数值列要求全部非空内容为普通十进制，绝对值≤1e12、小数≤12位，前导零标识符保留文本。不猜日期、币种和百分比。
- Decimal 40位精度计算；`sumExact`保留合计，`meanExact`最多20位有效数字。数值列输出Excel数值；JSON数值与图表为有限精度展示，精确值另存统计表文本/JSON。
- 文档最多60000字/1000非空段落；仅提取DOCX主文档正文，不保留图片、页眉页脚或样式，不处理修订。来源序号针对提取后非空段落，不是页码。
- PPT最多18000字、50页、单标题60字。固定文本分页与版式，不宣称完成商业提案或渲染验收。
