# 第八批：多文件多表精确关联与来源追踪

更新：2026-10-16。新增 `table.join-multi@1.0.0`，绑定数据分析专家。这是实际可执行的确定性CSV跨文件关联子集，不是AI业务口径理解、字段自动发现、复合键推断或真实数据源连接器。

## 输入包结构

上传一个ZIP，顶层须且只能含2–5个CSV文件与`joins.json`，不得放文件夹、宏、额外文件、路径、密码或其他压缩格式。UTF-8 CSV首行为不重复字段名，后续行须与表头列数相同。

```json
{
  "joins": [
    {"left":"orders.csv","right":"customers.csv","leftKey":"customer_id","rightKey":"id","type":"left","as":"orders_customers"},
    {"left":"orders_customers","right":"products.csv","leftKey":"orders.csv.sku","rightKey":"sku","type":"left","as":"sales_detail"}
  ],
  "output":"sales_detail"
}
```

按声明顺序执行1–4步；左侧可以是原CSV或前序结果别名，右侧是尚未关联的CSV。字段可用原始表头；多步产生同名字段时，使用精确限定名`文件名.csv.字段名`。类型仅left/inner/full。`joins.json`不接受额外键、未知源、反向依赖或重复别名。示例下载不自动执行；每次执行仍需要上传授权。

## 真实处理规则

- 安全读取ZIP中央/本地目录，限定存储/Deflate压缩，逐条校验边界、展开大小、长度与CRC；无落盘解压。最多5份CSV+清单，输入ZIP≤2MB、展开总量≤6MB、每文件≤2MB。
- 每表需表头及数据，最多5000行、50列、100000格；字段头唯一，单元格≤10000字符。拒绝非法UTF-8、畸形行、重复标题、未知/隐藏的压缩条目。
- 字段值保留CSV文本原样：`001`不等于`1`，前后空格/大小写不归一化，空键永不匹配；不猜日期、币种或业务类型。
- 每步右侧非空关联键必须唯一，遇到重复立刻失败，禁止隐式多对多行膨胀。左侧重复键可分别匹配到唯一右侧记录。内/左/全外连接实际生成对应集合。空右键不扩展，空左键未匹配。
- 1–4步，单步最多5000行/100000格，中间累计最多10000行，最终XLSX≤8MB。任何一步超限/失败则不返回部分工作簿。
- 输出真实`multi-joined.xlsx`，包含“关联结果”和逐原CSV的“来源行号”两张工作表；`multi-join-report.json`报告源ZIP SHA256、关联规则、数据大小、行数、来源列和限制；后台另附执行凭据。文本中的`=...`以字符串单元格写入，不解释公式。所有者隔离使用现有执行服务。
- 输出不去识别隐私，不核验数据权利、事实、业务口径或关联准确性；不转换/运行公式，不解释缺失值，不自动一对多展开，不连接数据库或实时API。请业务人员抽样比对来源后再使用。

### 自动规划及专家边界

ZIP 文件可进入数据专家的自动规划候选集，但规划器看不到压缩包内容，不能臆造文件名、字段、连接顺序、键或业务语义。唯一允许的规划是无推断参数地调用此技能；精确操作须由用户 ZIP 内的 `joins.json` 声明。若所需关系未在其中明确表达，规划器必须追问或拒绝，不得猜测。其他多步任务仍遵循规划器的一般限制。数据专家能力边界也已更新为该受限跨文件子集；不表示数据分析整体完成。

此能力仅完成数据专家“多表关联/跨文件关联”的受限子集。尚无业务口径理解、自动键发现、多对多规则、跨工作簿Excel导入、公式重算叠加或外部数据库连接器；不等于数据分析专家整体完成。
