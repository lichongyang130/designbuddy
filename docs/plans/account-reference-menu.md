- 设置、外观、记忆与进化分别打开现有设置页。外观目前仍为灰白外观说明，不声称已有主题切换；长期记忆尚未接通。

- 加油站、邀请、成长计划打开对应能力说明，不伪造充值、邀请链接、签到或领奖成功。

- 退出不删除本机项目、对话、通知或草稿；访客模式不可执行账号退出。
