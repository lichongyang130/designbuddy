## 使用入口与流程

**更多 → 专家 → 查看详情 → 已接通技能 → 描述任务，让模型建议技能**。技能总页也提供相同入口；专家详情内固定该专家，技能总页可从12位核心专家的已接通技能中选择一位。

1. 输入不超过4000字的任务，选择不超过2MB的文件。浏览器先计算SHA-256，不上传正文。
2. 单独勾选允许向模型发送任务描述、文件名、字节数，再点击“生成技能方案（不执行）”。没有勾选时不调用模型。SHA-256发送给应用后台绑定文件，但不发送给规划模型。
3. 查看原始任务、主专家、技能及版本、建议理由、实际交付、能力边界、冻结参数、文件哈希、有效期。模型不能看到正文，也不能承诺已经检查正文或完成任务。
4. 需要澄清时，选项只补充草稿，不自动再次调用模型或执行。不支持、模型失败、取消、过期都不是任务成功。
5. 再次单独勾选上传和执行同意，点击“确认方案并执行一次”。这时才上传文件正文至应用后台。固定执行器校验内容并处理，规划模型不接收文件正文。
6. 结果出现在“我的运行记录”，包含实际产物下载、输入/产物哈希、过程和方案确认信息。执行器报告成功不代表静态规则所检查的业务已经全部验收通过。

刷新后恢复方案及运行记录，但浏览器文件与同意复选框不恢复。必须重新选择同名、同大小、同SHA-256文件才能确认。编辑上方草稿不改写下面已保存的冻结方案；新任务需重新规划。

模型凭据沿用应用 **设置 → AI Provider** 的当前浏览器会话设置，或由管理员设置服务器环境变量。不要把密钥写进任务描述或聊天。未配置/不可达时如实失败；下方手动执行仍可用，而且不调用模型。

## 后端实现与安全边界

- 新增鉴权后的 `GET/POST /api/skill-plans`、`GET/DELETE /api/skill-plans/:id`、`POST /api/skill-plans/:id/cancel`。记录、确认与删除全部按当前服务端身份隔离。
- 候选技能由后台版本化注册表过滤：必须已接通、支持文件扩展名、符合固定专家范围。模型只能返回严格校验的 `plan / clarify / unsupported` 之一；未知技能、额外字段、任意命令、参数越权或专家越界均拒绝。扩展名筛选不能替代执行器对真实文件的校验。
- BYOK供应商地址来自固定允许清单，不接受用户提供服务URL；禁止跟随重定向。管理员的 `AI_BASE_URL` 是受信任部署配置。每次规划20秒上游期限、32KB上游响应上限、1200输出token请求上限，错误不暴露原始供应商响应或凭据。
- 任务描述和文件名是模型输入，不是可信指令。系统提示限制不能用静态检查冒充动态测试、用缩放冒充抠图、用ICS导出冒充日历同步等；这是提示与工具白名单约束，不是模型判断准确率证明，仍需用户核对。
- 方案保存原始任务、文件身份、专家范围、决策、技能版本、创建和过期时间及摘要；不保存模型API Key。摘要是内容一致性校验，不是密码学签名或身份令牌；授权依靠鉴权、所有者隔离和服务端冻结记录。
- 有效期15分钟。确认接口只接受方案ID、摘要、文件和明确同意；不允许请求方覆盖专家、技能、参数。服务器重新计算实际上传字节哈希，复查文件名/大小、方案状态、期限、注册表可用性及版本。
- 一次SQLite事务同时写入任务、提交去重记录，并把方案标记为已提交。重复确认返回同一任务；已删除的任务返回410，不自动重新执行。事务任一步失败，三项一起回滚。
- 方案请求ID同样去重；相同ID换任务返回409。删除方案仍保留请求去重凭据，原请求不会再调用模型。取消能中断在途规划，晚到的响应不能恢复待确认状态。取消不代表已发送给供应商的数据被撤回或费用被退回。
- 手动执行UI也发送请求ID：相同文件/参数重复提交复用任务，网络失败重试沿用ID；需要新任务请重新选择文件。为了兼容旧调用方，后端仍接受不带请求ID的手动请求，它们每次是新任务，不具有跨请求去重保证。
- 上传/规划等敏感操作遇到401身份变化，不会在新身份下自动重放；组件丢弃过期响应并撤销文件/授权状态。晚到的运行读取不会重新显示本页面已删除的运行。
- 响应丢失时，读取已持久化方案和对应任务恢复状态，不靠再次调用模型推测结果。服务重启将中断的规划标记失败，不自动重新请求模型；已经提交的运行沿用既有重启处理策略。

## 配额、持久化与部署

- 每身份最多保留50份方案；滚动24小时最多20次规划尝试，全局200次。规划并发每身份1个、全局4个。重复请求不重复计数；删除不重置当天尝试次数。失败/无合适工具的尝试也计入本地限额；这些不是供应商实际账单或token费用统计。
- 手动/确认执行共用每身份滚动24小时500次提交限制；已有2个并发worker、20个排队/运行任务、每身份100条运行、输入/产物与存储限制保留。
- 方案和去重表放在已有 `DESIGNBUDDY_SKILL_DB` 数据库中，启动自动创建表，不迁移/删除原运行文件。仍要求一个数据库仅由一个调度服务实例负责；不是多实例分布式队列。
- 原始材料只在确认后进入原运行存储；删除方案不删除已提交的运行和产物，须在运行区单独删除。去重墓碑保留请求标识、哈希指纹、方案/运行ID及时间，不含文件正文、明文目标或密钥。SQLite删除不是磁盘安全擦除；部署者需负责数据备份、访问控制与介质保留策略。
- 没有新增生产依赖。服务端代码变更需重新编译并重启，前端开发热更新不能替代后端重启。
- 此应用的文件正文不交给本轮规划模型；用户自行填入任务描述的内容仍属于会发送给供应商的文本，其保留政策不由本地数据库删除控制。

## 文件

- `shared/skillPlanning.ts`：文件身份、方案、严格决策及请求契约。
- `server/skills/contracts.ts`：请求与参数白名单。
- `server/skills/planner.ts`：受限候选、元数据提示、供应商适配、期限/响应体上限。
- `server/skills/plan-store.ts`：持久化、所有者隔离、规划去重、预算、取消和确认校验。
- `server/skills/service.ts`：原运行队列集成、审批事务、提交去重、确认凭据。
- `server/api/http-handler.ts`：复用现有鉴权入口。
- `frontend/workspace/SmartSkillPlanner.tsx`：双阶段同意、方案核对、恢复/取消、手动降级提示。
- `frontend/workspace/SkillWorkbench.tsx`：手动去重、真实执行与方案凭据、过期读取保护。
- `apps/web/src/api/client.ts`：敏感请求可禁止身份变化后的自动重放，其他调用方保留原行为。

## 验证方法与明确限制

新增16项服务端测试：严格元数据/决策、权限、篡改、期限/版本、重复确认、取消竞态、请求去重墓碑、配额、重启、密钥不落库、API鉴权、事务回滚、受限模型传输及真实worker输出/凭据。

新增11项浏览器测试：双阶段同意、只发送元数据、刷新/重新选文件、澄清不自动发送、不支持/失败降级、手动去重、响应丢失恢复、取消晚到结果、两条敏感链路的身份变化、晚到读取不恢复已删除运行、手机布局。部分用例同时覆盖多个风险。另有未拦截网络的实际HTTP测试验证未配置模型时如实失败。

模型响应使用明确的测试替身；规划浏览器流程将请求桥接到隔离的真实SQLite服务，**没有mock执行器成功、文件计算或产物内容**。本轮检查真实CSV去重统计结果为2条、合计30，并检查执行凭据。既有PDF/OCR、Office、图像、排期和静态检查回归继续保留。

**没有进行真实供应商的规划准确率验收。** 当前环境的模型未配置路径已验证；供应商网络、权限、模型兼容和真实任务选型仍需部署环境的凭据与联网条件验证。不能把这些受控测试数量称为36个真实专家业务任务完成。

最终回归结果记录在下方，未支持项不会因此改变：全自主多步工具循环、管理员控制台/成本账单、扫描PDF批量OCR、专业PPT创作与真实渲染、生成式图片/精细抠图、隔离全栈开发/动态浏览器/API测试、授权日历/邮件/发布仍未完成。首页聊天仍是指导和专家匹配，不会因为发送聊天消息就在后台执行技能；本轮执行入口在技能执行台。
