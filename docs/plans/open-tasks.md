本轮修掉的真实产品 bug：

1. **右侧预览抽屉遮挡发送按钮**（上一轮）：输入区用 `ResizeObserver` 实测高度写入 `--task-composer-h`，抽屉停在其上方。
2. **插件生命周期卡片在 320px 横向溢出**（第四轮，全量回归首次暴露）：`.pm-lifecycle-grid` 的 `minmax(280px, 1fr)` 改为
   `minmax(min(280px, 100%), 1fr)`，并在 ≤680px 收窄内边距；修复后 320px 下 `scrollWidth` 回到 320。
3. **手机屏幕上编辑器头部按钮点不到**（第五轮，验收工具在 390×844 视口暴露）：≤760px 时头部操作行换行，
   但 `.db-editor-header` 高度写死 62px，第二行溢出并被文件列表盖住；改为 `flex: 0 0 auto` 让头部随内容变高，
   并补了回归用例（`project-versions.spec.ts` 第三项）。
4. **冲突检测被自己人的"刷新"逻辑废掉**（第五轮）：本地编辑会把 `cloudSaved` 置回 false，进而触发"重新拉取服务器最新版本"，
   把基线刷成服务器当前版本，冲突因此检测不到；改为只在切换项目时拉取历史，本地编辑不再改写基线。
5. **409 冲突被当成"请求失败"**（第五轮）：`readJSON` 在非 2xx 时先抛错，编辑器拿不到冲突明细；改为直接解析响应体并抛 `ProjectConflictError`。

6. **账号表加列后注册直接 400**（第七轮）：`workspace_accounts` 增列后，`INSERT INTO workspace_accounts VALUES(...)`
   变成"7 列给 5 个值"，注册接口被 catch 吞成"账号请求无效"；改为显式列名插入。
7. **验收工具"点击后立刻断言"读到旧提示**（第七轮）：断言在点击后马上读文本，拿到的是上一条提示，
   于是把成功误判成失败；`assertText` 改为最多等 8 秒等目标文本出现。
8. **Node 不接受带 chunked 体的 DELETE**（第七轮）：Node 的 HTTP 解析器会拒绝 DELETE + chunked 请求体
   （直接回 400 空响应），测试用例会误判为服务端故障；测试辅助改为显式带 `Content-Length`
   （浏览器 fetch 本来就带长度，不受影响）。

本轮同步更新的过期断言：侧栏导航项由 5 项改为 7 项（新增「模型与用量」「账号与数据」）。
