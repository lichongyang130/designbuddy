## 已实现的真实链路

仍使用第一阶段的鉴权、所有者隔离、持久化队列、取消、超时和成果下载。新增执行器全部经同一任务服务运行，不在前端模拟成功。

- PDF：pdfjs-dist读取数据缓冲区，不加载用户URL或执行PDF脚本；不支持加密，最多40页/60000字。每页记录来源，混合扫描/文本文件明确报告缺失页，全无文字时失败，不假称读完。
- PDF输出：pdf-lib + 本仓库已有Noto Sans SC子集内嵌字体，实际写入可选中文字。字体缺字时报错，不静默丢字。附字体OFL许可。
- OCR：本地Tesseract中英文LSTM模型；没有向外部API发送材料。返回文字、行框、置信度及模型SHA-256。置信度不是准确率认证，尤其姓名、金额必须复核。
- 图片：Sharp只接受真实PNG/JPEG/WebP，拒绝SVG/伪装图片/动画、超过1200万像素或8000边长。OCR再限制600万像素。生成结果不继承EXIF，图像尺寸不修改商品本体。
- 海报：服务器白名单校验标题/副标题/行动文字；文字用本地字体转轮廓，避免依赖操作系统中文字库或SVG文本注入。实际光栅化为PNG，可预览/下载；参数保存到运行凭据。
- 排期：时间要求显式时区，检查真实日期、结束顺序、同负责人重叠、缺失依赖、循环依赖、前置顺序。任一问题都不输出ICS；检查通过才转换UTC并生成正确UTF-8折行的ICS。
- 需求：最多300需求/600验收条目，校验结构与引用。执行成功仅表示检查程序生成了报告，不表示需求验收通过。
- HTML：parse5解析并记录位置，不渲染或执行脚本；输出纯文本/JSON问题，不输出不受信任页面预览。
- JavaScript：Acorn只解析AST，报告语法错误与有限风险规则；不运行代码，也不声称漏洞可利用或已经修好。

输入格式示例可从执行台下载，下载不创建任务。没有填写格式/图片参数、没有上传同意时不能执行。技能总览默认折叠，专家详情直接展示绑定技能；旧自建数据与历史运行保留。

## 部署与依赖

- Node **22.13+**，依赖及锁文件已更新。
- 保留仓库 `apps/web/src/assets/fonts/` 及OFL许可；非仓库根目录运行时设置 `DESIGNBUDDY_ASSET_ROOT` 为仓库根。
- OCR紧凑模型来自已安装的 `@tesseract.js-data/chi_sim` / `eng` 包，首次运行校验并复制到 `data/skill-models/ocr-v1`，不是运行时联网下载。可通过管理员环境变量 `DESIGNBUDDY_OCR_MODEL_DIR` 指定目录。文件位于Git忽略的数据目录，不把模型大文件加入版本库。
- Tesseract v7 + 大模型内存传递在实测中导致子线程内存错误，改为v6.0.1及本地紧凑模型路径后，真实OCR和有资源限制的后台worker均通过。没有把失败版本留给用户。
- PDF依赖审计发现旧版本漏洞后，已更新pdfjs-dist至6.4.299；最终 `pnpm audit` 返回0条已报告漏洞。这不等同安全认证。
- Worker内存/时间限制不等于容器隔离。固定图像/PDF/OCR原生组件仍需部署层总内存/进程治理；任意代码执行仍禁止。
