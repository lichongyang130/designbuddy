# 首页二级栏目与提示词推荐列表

日期：2026-10-15

## 已实现交互

1. 点击输入框上方胶囊分类，只展开二级栏目，不填充、不发送问题。
2. 点击二级栏目，在「热门场景」中显示对应的三条推荐任务列表，更新栏目路径；每栏有六条任务供轮换。
3. 点击具体列表项，向输入框填入完整提示词并聚焦。已有不同内容时仍先确认替换；取消不改变输入，也不记录使用次数。附件、模型、工作空间和权限保留。
4. 原「查看更多」替换为「换一批」，不跳转页面、不改变输入、不调用聊天/生成接口。相邻两批无重复，轮完该栏后允许再次推荐。
5. 三种模式分别维护所选栏目，不串用分类。分类菜单支持键盘上下键、首尾键、Escape、外部关闭和焦点返回；手机端菜单不会超出屏幕。

## 分类与提示词

- 办公模式五个一级分类各有三个二级栏目：
  - 文档处理：总结提炼、撰写与编排、润色与校对。
  - 图像创作：办公配图、社媒与宣传、提示词优化。
  - 数据分析：清洗与检查、业务洞察、可视化报告。
  - PPT制作：工作汇报、方案提案、培训与分享。
  - 智能助手：计划与执行、沟通与协作、比较与决策。
- 代码开发、设计创意各保留五个独立一级分类，每类提供制作/实施与审查/优化两个二级栏目。
- 合计 15 个分类、35 个二级栏目、210 条完整提示词；每条包括具体任务目标、栏目要求、模式执行约束、材料确认、证据边界与交付检查。
- 自动校验全部提示词的中文汉字数，最短为 **445 字**，不以数字、标点或英文计入「至少 200 字」要求。
- 这些是提示词条目，不是新增社区作品；180 套模板实施进度没有因此增加。

## 推荐方式与隐私

采用可解释的本机规则推荐，不冒充云端 AI 实时生成：

- 优先限制在当前模式和选定栏目内。
- 以输入文本中的中文双字词与英文关键词匹配任务标题和描述。
- 根据本浏览器的使用次数小幅调整顺序，换批优先展示本轮尚未看过的任务。
- 选择栏目（含重新选择当前栏目）及换批时重新匹配；用户打字时不让列表不停跳动。
- 仅存储任务 ID、次数、最近使用时间，不保存或上传输入正文。历史不可用或损坏时不阻断填入提示词。
