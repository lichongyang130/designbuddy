  x1538–1609，y100–130）、`钱包余额` + 同行小字 `Design Plan 额度用尽后，自动使用此余额按量付费。`

## 边界

- 横幅渐变是 CSS 生成的装饰图形，不是截图里的原图，也不是任何品牌素材。
- `$0.00`、可用 `0`、禁用开关都表示「未接入」，不是账单账户余额；不会创建订单或扣费。
- 设置里的个人主页只展示套餐与额度状态；账号资料、记忆、导出/注销等操作仍在 `/profile`。
