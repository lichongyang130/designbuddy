## 边界

- **面板里的版本、余额、用量与日期是参考截图的静态展示内容，不是真实数据**：
  这个版本没有接入积分、订阅或支付服务，这些数字不会被写入、扣除、充值或同步，
  也不能用来推算任何账单。UI 里没有加说明是按用户要求；这里如实记录。
- 下方「用量与套餐」卡里的项目/对话/副本/修改/模型/存储数字仍来自本浏览器真实统计，
  并保留「不会产生订阅或扣费」的说明。
- 「升级套餐」不会下单，打开的是真实的「付费套餐暂未接入」弹窗；「查看明细」跳转
  个人主页的账号与数据，这是应用里真实存在的页面。
