# 图层自由排版验收证据 · 2026-10-16

范围与限制见 [第六批实施记录](../../plans/poster-layout-execution.md)。这是实际执行证据，不是全部高级任务或商业业务验收通过的声明。

- `default-service/`：原创六层960×1200版式示例，通过真实服务队列/worker生成的六份产物。用 `node scripts/verify-poster-layout.cjs` 可重新执行，数据库仅在内存中，不操作应用持久数据库。
- `edited-browser/`：通过真实浏览器修改两行中文、坐标及导入红蓝PNG后上传执行并下载的六份产物。红蓝块用于裁剪、层级和哈希验证，遮盖文字是测试排列，不是成品活动海报。
- `screenshots/`：真实桌面画布、编辑后后台PNG、320/390px画布及输出、390px属性面板，共7张。全部裁在编辑器/产物范围，不含账号侧栏。
- `logs/`：13项后端专项、136项后端回归、8项浏览器专项、169项相关回归、补跑6项信息图、最终8项排版复验、9项目录、生产构建、服务产物核验及注册表状态。
- `results.json`：执行顺序、准确计数、检查结果、源文件与本目录证据SHA-256。截图/测试样例不充抵36个真实业务案例。

源码验证前需编译后端；普通环境需安装Playwright浏览器。服务包含可选ASR安装时为20项就绪，无ASR为19项。模型包不随此证据目录保存。

测试累计为175个不同浏览器用例（169+补跑6），不是一次运行175项，不重复累计排版专项。随后仅增加截图和延迟读图身份隔离断言，排版8项再次全部通过。全站浏览器、真实模型选型、PowerPoint渲染、外部服务和生产部署不在本次通过范围。
