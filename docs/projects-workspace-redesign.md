# 我的项目：工作区统一改版

入口：`/projects`。本次沿用主应用的 `WorkBuddySidebar`，不再使用独立旧版 `db-page` 布局。

## 界面与行为

- 239px 桌面侧栏、72px 顶栏，延续主应用的浅灰导航、白色内容区、细边框与克制的主操作。移动端沿用共享导航的折叠布局。
- 项目卡片展示实际文件路径、需求摘要、草稿状态、工作空间与更新时间；文件概览不是网页截图，不执行项目 HTML/JavaScript，也不伪造项目预览。
- 搜索名称/需求、工作空间与未分组筛选、最近更新/最近创建/名称排序、卡片/列表切换均有实际行为。无项目、搜索无匹配和筛选无匹配分别处理。
- 新建与继续操作保留 `projectTaskPath`：已有本机对话去 `/tasks/:id`，否则去 `/editor/:id`。
- 云端/团队项目仍由用户手动载入，替换不同的本机副本前须确认；不自动上传，不将“已载入”声称为双向同步。
- 删除只移除本机草稿，保留确认；创建与删除遇到存储失败时显示错误。其他标签页的本机项目变化及窗口重新聚焦会刷新列表。
- 深色模式使用共享主题变量；长标题、长需求、长工作空间名及无效时间均有降级显示。

## 同次提交的安全整理

提交前检查发现旧 AI 请求、聊天、专家匹配、模型目录及额度接口存在硬编码凭据回退，已全部移除。没有显式配置凭据时必须报未配置，不尝试使用内置凭据。新增缺配置拒绝外呼测试，并运行这些接口的相关回归。

AI 调用需要设置中的用户自备凭据或服务端 `AI_API_KEY` / `OPENAI_API_KEY`，服务地址与模型须与所选供应商匹配。旧凭据可能仍存在于既有 Git 历史中；本次不改写历史，仓库所有者应在供应商后台撤销并轮换这些旧凭据。

安装依赖、构建输出、缓存、浏览器测试会话、本机数据库、上传资料和环境密钥不提交。`docs/verification/**/logs/*.log` 是经过扫描的精选验证证据，不是运行日志。
