## 边界

本目录保存的是设计概念稿；后续已把 07 实现为应用欢迎页，并接入账号密码、第三方登录入口与模型设置入口，详见 `docs/verification/welcome-2026-10-19/README.md`（仓库路径）。Google / GitHub 真实授权仍需服务器凭据。本目录独立原型的按钮不执行这些业务操作。主视觉由本轮图像工具新生成，没有复用截图画作来充当新图，也不保证生成素材的独占权或商业法律验收。字体沿用仓库 NotoSansSC，原始 OFL 随附。没有通过应用后端配置的图像供应商发出请求。

```bash
python3 designs/visitor-welcome/serve.py --port 5180

node designs/visitor-welcome/render.cjs
```

源稿按 1440 × 1000 桌面尺寸绘制；对比画廊与查看器另有窄屏排版。ZIP 仅包含已完成的 PNG 和说明，源稿在仓库同目录。

## 画廊加载修复

页面为概念数据脚本添加内容版本号、为缩略图及成品大图添加版本参数；画廊按实际导出清单判断图片是否完成，不再把旧版脚本缺失的字段误判为“待生成”。预览服务关闭 HTTP 缓存。清单加载失败时显示失败原因及重新加载入口，不再显示虚假的待生成提示。
