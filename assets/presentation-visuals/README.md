# M2 概念配图来源

`concept-hero.jpg` 在本次用户批准的视觉升级中，通过 Arena 图像工具实际生成一次。

- 类型：抽象玻璃/陶瓷雕塑概念装饰；没有真实产品、人物、第三方Logo或文字。
- 用途：本项目内置三种艺术方向示例中的气氛配图，不是业务事实、产品功能或经营结果证据。
- 来源边界：不是 DesignBuddy 后台 `image.generate` 自动生成的结果；本次没有触发应用自动生图。
- 许可边界：本项目概念展示用途声明；不声称 CC0、第三方授权已核验或 AI 生成物必然无权利风险。
- 导出：使用项目安全素材管线校验、去EXIF、规范化为PNG，原始与规范化SHA256记录在每份示例的 `visual-plan.json`。

另两份示例素材由 `scripts/generate-presentation-visual-directions.cjs` 派生：

- `asset-screenshot`：已冻结 V2 实际第04页 JPEG 的完整规范化栅格。没有OCR、不作为当前源码审计、不增加业务结论。
- `asset-mark`：本地 Canvas 绘制的 `DB / CONCEPT` 示例标识，非第三方Logo；不宣称第三方品牌授权。
