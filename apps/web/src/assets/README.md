# Homepage reference assets

`home-avatar.png` is a small crop from the user-provided
homepage reference at repository root (`1.png`). It is used only as a decorative
image to reproduce that reference; the rest of the homepage is live HTML/CSS.
Confirm rights to the supplied branding before public distribution.

The `experts/` directory contains two banner illustrations and six avatar crops
from the user-provided expert reference (`2.png`). Titles, descriptions, links,
filters and cards are real UI elements, not part of those images. These supplied
reference assets do not imply official endorsement of the example expert roles.

The `skills/` directory contains twelve icon crops from the user-supplied
[7.png skill-market reference](https://github.com/lichongyang130/new/blob/main/7.png),
Git blob `5a0c84137c741c89dc66270e1d2fc4fd4dc5cfe5`. Card text, layout, installation
controls and filters are live UI, not a screenshot background. Third-party names
and icons are reference/demo content, not an assertion of integrated services.

The `connectors/` directory contains nineteen icon crops from the supplied
[8.png connector reference](https://github.com/lichongyang130/new/blob/main/8.png),
Git blob `58df151e31d28e4ef7b0be255d81b0e4b3367d26`. They reproduce the reference
branding only. Catalog descriptions are illustrative; actual integration status
and requirements are stated in connector details.
